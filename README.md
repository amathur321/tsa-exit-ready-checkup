# TSA Exit-Ready Finance Check-up

Landing page for Tech Savvy Accountants: a 15-question exit-readiness scorecard.
Visitors answer the questions, enter their email to see their score, and can book a free conversation.

- Static site, one file (`index.html`), hosted on GitHub Pages.
- Content source: `AMA-OS/1-Business/AMA/03_output/marketing-content/TSA_One-Pager_Exit-Ready-Finance-Checklist_v1_2026-10-29.docx`

## Before launch
1. Set `FORM_ENDPOINT` in `index.html` to the HubSpot form submission URL.
2. Replace the `#` placeholders for the booking link, privacy policy and PDF checklist.
3. Remove the `noindex` meta tag.
